What is Pandas and what is it used for?;Pandas is a Python library designed for working with tabular data, such as CSV files or database tables. It provides tools for data manipulation, cleaning, and analysis.

Why is Pandas considered advantageous over other approaches like Excel?;Pandas offers reproducibility since code serves as documentation that can be run again by anyone. It also integrates well with charts and machine learning tools and performs faster calculations due to its foundation on NumPy.

What are the two main data structures in Pandas?;The two main data structures in Pandas are DataFrames, which represent entire tables with rows and columns, and Series, which is a single column from a DataFrame.

How do you load a CSV file into a Pandas DataFrame?;You use the `pd.read_csv()` function, passing the file path as an argument to create a DataFrame from the data.

What does the `.shape` attribute of a DataFrame tell you?;The `.shape` attribute returns a tuple showing the number of rows and columns in the DataFrame, e.g., (4574, 84) for 4574 rows and 84 columns.

How can you check the data types of columns in a DataFrame?;Use the `.dtypes` attribute to see the data type of each column in the DataFrame.

What is the purpose of the `.describe()` method in Pandas?;The `.describe()` method generates summary statistics for numeric columns, including count, mean, standard deviation, minimum, quartiles, and maximum values.

How do you select a single column from a DataFrame in Pandas?;You can select a single column using square brackets with the column name like `df['column_name']`, which returns a Series.

What is the difference between selecting one column and multiple columns in Pandas?;Selecting one column returns a Series, while selecting multiple columns using double brackets like `df[['col1', 'col2']]` returns a DataFrame.

How do you filter rows in a DataFrame based on conditions?;You create a boolean mask using comparison operators (e.g., `df['column'] == value`) and then apply it to the DataFrame with `df[mask]`.

What is a boolean mask in Pandas?;A boolean mask is a Series or DataFrame of True/False values that can be used to filter data, typically created by applying comparison operations to a column.

How do you sort a DataFrame by one or more columns?;Use the `.sort_values()` method with the column name(s) as an argument. You can specify ascending or descending order.

What are some common methods for handling missing data in Pandas?;Common methods include checking with `.isna()` or `.isnull()`, counting missing values using `.count()`, and filtering out missing data using `.notna()` or `.notnull()`.

How do you reset the index of a filtered DataFrame?;Use the `.reset_index(drop=True)` method to reset the index to sequential numbers starting from 0.

What are some key takeaways for working with Pandas DataFrames?;Key takeaways include loading data with `pd.read_csv()`, exploring data with `.shape`, `.info()`, and `.describe()`, selecting columns using single or double brackets, filtering with boolean masks, sorting with `.sort_values()`, and handling missing data appropriately.
