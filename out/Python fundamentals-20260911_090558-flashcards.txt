What is Git?;Git is a distributed version control system that tracks changes in files over time and allows multiple developers to collaborate without conflicts.

What is GitHub?;GitHub is a web-based platform that hosts Git repositories and provides tools for code management, collaboration, and project tracking.

Why use Git and GitHub?;They help track changes, enable collaboration, provide backup, maintain organized history, and allow easy reverting to previous versions.

How do you initialize a Git repository?;Run `git init` in the desired directory to create a new Git repository with a hidden `.git` folder.

How do you add files to Git for committing?;Use `git add <filename>` to stage specific files or `git add .` to stage all files in the current directory.

What is a Git commit?;A commit is a snapshot of your project at a point in time with a descriptive message explaining what changed.

How do you push changes to GitHub?;First set up a remote repository using `git remote add origin <url>`, then run `git push -u origin main`.

What are good practices for Git commit messages?;Keep them short (2-3 words), descriptive, in present tense, and specific about what changed.

How should you organize lab projects in Git?;Create one folder per lab to keep projects organized and make it easier to track individual work.

What is the purpose of `.gitignore`?;It excludes unnecessary files like compiled code or cache directories from being tracked by Git.

How do you handle permission errors when pushing to GitHub?;Ensure your SSH keys are configured or use HTTPS with proper credentials for authentication.
