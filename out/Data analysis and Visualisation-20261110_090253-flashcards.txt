What does the `value_counts()` method do in pandas?;It counts how many times each unique value appears in a column and returns a Series sorted by frequency in descending order.

How can you calculate proportions instead of absolute counts using value counts?;Use the `normalize=True` parameter to convert counts into proportions that sum to 1.0.

What happens if you don't exclude missing values when using `value_counts()`?;Missing values (NaN) will be included in the result and displayed as 'nan'.

What are the three steps involved in a group by operation?;Split the dataset into groups, apply an aggregation function to each group, and combine the results.

How do you perform multiple aggregations on grouped data using `agg()`?;Pass a list of function names to `agg()` to apply each function to all numeric columns in the group.

Can you specify different functions for different columns when grouping data?;Yes, by passing a dictionary to `agg()` where keys are column names and values are the aggregation functions.

Why is it important to clean price data before performing mathematical operations?;Price data often contains non-numeric characters like currency symbols and commas that prevent calculations.

What should you check before performing calculations on a dataset?;You should verify that columns have appropriate data types (numeric) before doing mathematical operations.

How can group by operations help identify data quality issues?;By examining value counts and group statistics, you can spot missing values, unexpected patterns, or outliers that may indicate errors.

What is the advantage of using median over mean when interpreting small sample groups?;Median is more robust to outliers and provides a better representation of central tendency for small or skewed datasets.
