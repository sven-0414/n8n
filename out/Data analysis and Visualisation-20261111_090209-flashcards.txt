What is the primary purpose of data cleaning in data analysis?;Data cleaning involves identifying and correcting errors, inconsistencies, and missing values to ensure reliable and accurate results.

Why is data cleaning important for decision making?;Clean data provides a solid foundation for business decisions by ensuring accuracy and trustworthiness of the information used.

What are the six standard steps in the data cleaning process?;1. Look at the data, 2. Identify problems, 3. Fix problems one at a time, 4. Check results after each fix, 5. Never change the original data, 6. Write steps as code for reproducibility.

How should you handle the original dataset during cleaning?;Always work on copies of the original data and maintain backups to prevent accidental loss or modification of the source data.

What are common issues found in text columns during data cleaning?;Inconsistent capitalization, extra spaces, different spellings, and mixed formatting can cause problems in text columns.

How do you standardize text values in Python using pandas?;Use `.str.strip().str.lower()` to remove leading/trailing spaces and normalize case.

What technique is used to handle specific inconsistencies in text data?;The `.replace()` method allows replacing inconsistent values with standardized ones.

How do you convert text representations of numbers into numeric types in pandas?;Remove formatting characters, then use `pd.to_numeric()` with `errors='coerce'` to handle invalid entries.

What function converts text dates into proper datetime objects in pandas?;The `pd.to_datetime()` function converts text date strings into datetime objects.

How can you detect duplicate rows in a dataset using pandas?;Use the `.duplicated()` method which marks all duplicate rows except the first occurrence.

What is the recommended approach for removing duplicates from a dataset?;Use `drop_duplicates()` to remove duplicate rows while keeping the first occurrence of each unique row.

Why should you check for duplicates based on specific columns rather than entire rows?;It allows you to identify duplicates based on meaningful identifiers like order IDs, which may be unique even when other data is duplicated.

How do you remove completely empty columns from a dataset?;Use `drop(columns=[column_name])` after verifying that the column contains only missing values.

What is the benefit of creating calculated columns after cleaning data?;Calculated columns enable more advanced analysis and can provide insights not directly available in the original data.

Why should you save cleaned data to a file?;Saving ensures you don't have to repeat the cleaning process and allows others to reproduce your work.

What are key principles of good data cleaning practices?;Never modify original data, document everything, check your work, handle missing values thoughtfully, test with real analysis, and be honest about decisions made during cleaning.
